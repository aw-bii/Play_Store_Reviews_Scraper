How it works

Get reviews in four steps.

Just an app ID and you're done.

Enter App ID

From the Play Store URL - ?id=com.spotify.music is what you need.

Set filters

Pick country, sort order, and which star ratings to include.

Scrape

Hit "Start scraping" and reviews populate in real time.

Export

Preview the table, get an AI summary, or download as CSV or XLSX.

Run locally.

Clone, install, run.

# clone and install git clone https://github.com/aw-bii/Play_Store_Reviews_Scraper.git cd Play_Store_Reviews_Scraper pip install -r requirements.txt # launch streamlit run streamlit_app.py

Opens at http://localhost:8501
