Features

Everything you need to analyse Play Store reviews.

Scrape, filter, and export reviews in seconds — no API keys or setup required.

⌂

Bulk scraping

Fetch up to 10,000 reviews for any Google Play app using its app ID.

⌘

Smart filters

Filter by country, star rating, and sort order (newest or most relevant).

◉

Rating distribution

View summary metrics including average rating, 5-star count, and NPS at a glance.

⇩

CSV & XLSX export

Download scraped reviews as CSV or Excel files for further analysis.

✦

AI summaries

One-click AI-powered summary of reviews using Google Gemini.

◻

Version tracking

Optionally include the app version column in your export for trend analysis.

How It Works

Three clicks to reviews.

No accounts, no API keys — just an app ID and you're set.

Enter App ID

Copy the ID from any Play Store URL (?id=com.spotify.music)

Set filters

Choose country, sort order, star rating, and how many reviews to pull.

Scrape

Hit "Start scraping" and watch reviews populate in real time.

Export

Preview the data table, generate an AI summary, or download as CSV / XLSX.

Quick Start

Run locally in seconds.

Clone the repo, install dependencies, and launch.

git clone https://github.com/aw-bii/Play_Store_Reviews_Scraper.git cd Play_Store_Reviews_Scraper pip install -r requirements.txt streamlit run streamlit_app.py

Opens at http://localhost:8501
